# Imported Round-4 input scope

The draft, parameter JSON and vector JSON files in this directory are
immutable project-authored review inputs copied from the manifest-bound
Round-4 source tree. They are covered by the Apache License, Version 2.0,
reproduced at `../../LICENSE`, unless an individual file states otherwise.

Mathematical facts, parameter values, equations and algorithms are recorded
for reproducibility and are not claimed as original copyrightable expression.
Status or assurance labels retained inside an immutable imported file describe
that source artifact; they are not results for the current Rust candidate.

`ROUND4_SOURCE_MANIFEST.sha256` is preserved as source provenance. It is not a
manifest over this smaller input directory. `SHA256SUMS` is the operative
manifest for the files supplied here.
