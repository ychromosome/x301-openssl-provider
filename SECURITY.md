# Security policy

This repository is an experimental, pre-deep-scan implementation candidate.
It has no supported production version and must not process production keys.

Public issues are appropriate for ordinary correctness, build and
documentation problems. For a potentially sensitive vulnerability, use the
repository's private GitHub vulnerability-reporting channel when enabled. If
it is unavailable, open a minimal public issue requesting a private contact
without disclosing vulnerability details.

Please include the exact commit, platform, toolchain, build profile, input
classification, reproduction steps and observed result. Do not include real
keys, credentials or unrelated private data.

The current assurance boundary and deferred work are documented in
`ZEROIZATION_AND_CT_BOUNDARY.md` and `STATUS.md`.
